## ✨ Portfolio Key Features

- **Cinematic Hero Reel**: Full-screen AI-generated intro video with play/pause controls over a branded red theme.
- **Scroll-Driven Animations**: Framer Motion + AOS powered effects — animated process timeline, torn-paper section transitions, and a water-fill preloader.
- **Interactive Photo Galleries**: Hackathons, workshops, and campus events open in full-screen lightbox galleries with click-to-enlarge.
- **Real-Time Contact Form**: EmailJS-powered delivery straight to my inbox (with a graceful mailto fallback).
- **One-Click Resume**: Official resume PDF served directly from the site.

---

## 🛠 Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4, Framer Motion, AOS, Lucide-style inline SVGs
- **Email Delivery**: EmailJS
- **Deployment**: Vercel (auto-deploys on every push to `main`)

---

## ⚙️ Running Locally

```bash
npm install
npm run dev
```

> **Windows note:** if your project path contains `&`, `npm run` may fail — run `node node_modules/vite/bin/vite.js dev` instead.

**EmailJS setup (for the contact form):** copy `.env.example` to `.env` and fill in your `VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`, and `VITE_EMAILJS_PUBLIC_KEY`. On Vercel, add the same keys as Environment Variables.
